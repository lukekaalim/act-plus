# @lukekaalim/grimoire

```sh
npm i @lukekaalim/grimoire
```
> A documentation library package using [@lukekaalim/act](act.luke.kaal.im).

Grimoire is a collection of components, services, and utilities to help you scaffold
and design a website for documenting various kinds of coding related stuff.

## Features

  - **Web Bundler agnostic.** Its just a typescript library! Bundle with your main
    application, or host it on it's own platform.
  - **Plugin extension system.** Use some extra plugins for more specific tasks,
    or write you own to handle specific use cases!
