# DocBuilder

The DocBuilder is a utility that helps you construct a
documentation website, managing features such as:
  - Articles/Document contents
  - Links and References
  - Search Indices
  - Pages and paths
  - Demo Components

It also has a plugin system for extension with other
specific tools like:
  - Typescript/TSDoc API documentation with [grimoire-ts](./)
  - HTTP/REST API documentation with [grimoire-http](./)
