# Packages

Act Plus is the name for a collection of [NPM packages](https://www.npmjs.com/)
written by luke kaalim that are somewhat related to [`@lukekaalim/act`](https://act.luke.kaal.im),
but not core enough to act to be included in its repository directly.

This includes the Grimoire documentation library, which is used to display the website
you see before you, the animation/math library Curve, the mast-rendering Act-Markdown and
the Router library.
