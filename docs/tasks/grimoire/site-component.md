### Site Component

We should revist how we handle "themes" and the entry point.

  - [x] A `DocApp` should be a description of a documentation site.
  - [ ] A `DocSite` should be a component that renders out the whole website
  - [ ] A `DocTheme` should be a description of a set of components and styles that
    the DocSite can use to build itself out.
